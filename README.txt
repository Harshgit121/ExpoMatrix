# ExpoMatrix - From Blueprint to Booked

A complete web application for exhibition stall management. Organizers can generate layouts and vendors can book stalls in real time.

## 💡 Features
- Dynamic stall layout generation
- Entry/Exit management
- Real-time booking requests with status
- Organizer and Vendor panels

## 🔧 Technologies Used
- HTML5, CSS3, JavaScript
- PHP (Backend)
- MySQL (Database)

## 🚀 How to Run
1. Clone this repo
2. Import `database/database.sql` to your MySQL server
3. Set up with XAMPP or any local server
4. Update DB config in `backend/config.php`
5. Open `frontend/index.html` in browser

## 📂 Project Structure
- `/frontend` → UI Files (HTML, CSS, JS)
- `/backend` → PHP Logic & DB handling
- `/database` → SQL file for setup
